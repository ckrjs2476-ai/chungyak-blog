# 블로그 디자인 (2026-10-31 적용)

- 헤더: 각 블로그 테마 HTML의 `]]></b:skin>` 바로 앞에 `/* brand-css start … end */` 블록(brand-css.json). 배경 사진 대신 블로그 색 그라데이션 + 옅은 격자 + 주제 아이콘(SVG data URI). 테마를 바꾸면 이 블록을 다시 넣는다.
  - 청약 #0f2a4a→#1d4ed8, 전세 #5a1d0c→#d9480f, 공모주 #1e1b4b→#4338ca, 관리비 #053b2f→#047857, 드론 #083344→#0e7490
- 파비콘: 설정 → 파비콘에 <블로그>-favicon.png(48px로 줄여 업로드).
- 프로필(계정 공통): 표시 이름 '데이터노트', 사진 profile.png(Blogger가 이 저장소 raw 주소를 프록시로 가져감 → 이 파일을 지우지 않는다), 소개 문구 입력.
- 드론 블로그: 상단 페이지 목록 가젯 켜고 홈·소개·운영정책·문의·개인정보처리방침 추가, 블로그 설명 입력.
- 다시 만들기: python make.py (Playwright로 PNG 생성), python css.py (brand-css.json).

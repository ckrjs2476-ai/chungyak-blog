# 상위노출과 블로그 성장 규칙 (seo_guide.md와 함께 읽기)

seo_guide.md가 '글 한 편을 잘 쓰는 법'이라면, 이 파일은 '구글이 어떤 기준으로 순위를 매기고,
블로그 전체를 어떻게 키우는가'를 다룬다. 2026-10-05에 구글 공식 문서로 확인했다.
[공식] 구글 문서, [연구] 공개 연구, [관행] 업계에서 흔히 쓰지만 구글이 확인하지 않은 것.
[관행] 항목은 효과가 보장되지 않으며, 구글 정책과 충돌하면 버린다.

## 1. 구글 순위 시스템과 우리가 할 일 [공식]
구글은 공개한 순위 시스템 목록이 있다. 우리 블로그와 관련 있는 것만 추렸다.

| 시스템 | 무엇을 보나 | 우리가 할 일 |
| --- | --- | --- |
| 최신성(Freshness) | 최신 정보가 필요한 검색어에서 최근 글 우대 | 공고·경쟁률·당첨 발표 당일에 쓴다. 정정공고가 나오면 글을 고친다 |
| 원본 콘텐츠(Original content) | 원본을 파생 글보다 위에 | 단순 옮기기가 아니라 비교·계산(시세 대비, 지난 회차 대비)을 더한다 |
| 중복 제거(Deduplication) | 거의 같은 결과는 하나만 노출 | 같은 단지·같은 유형 글은 한 번만. 글마다 다른 숫자와 관점 |
| 사이트 다양성(Site diversity) | 한 사이트가 결과를 독차지하지 않게 | 한 검색어에 여러 글로 덤비지 않는다. 키워드 하나에 글 하나 |
| 문단 순위(Passage ranking) | 글 속 특정 문단만으로도 순위 판단 | 문단마다 그 자체로 답이 되게 쓴다 (단지명·숫자를 문단 안에) |
| 신경망 매칭·RankBrain·BERT | 단어가 정확히 같지 않아도 뜻으로 연결 | 키워드 반복 대신 사람들이 쓰는 여러 표현을 자연스럽게 (분양가/분양 가격, 줍줍/무순위) |
| 신뢰할 수 있는 정보 | 권위 있는 페이지 우대, 저품질 강등 | 출처(청약홈 공고) 명시, 숫자 검수, 틀리면 바로 수정 |
| 링크 분석·PageRank | 페이지 사이 링크로 관련성·권위 판단 | 내부 링크 체계(아래 3장). 외부 링크는 사러 다니지 않는다 |
| 완전일치 도메인 | 검색어와 같은 도메인에 과한 점수 주지 않음 | 도메인에 키워드를 억지로 넣을 필요 없음 |
| 스팸 감지 | 스팸 정책 위반 | seo_guide.md 1장 지키기 |

- '도움이 되는 콘텐츠 시스템'은 2024년 3월 핵심 순위 시스템에 합쳐졌다. 따로 대응하는 게 아니라
  모든 글이 사람에게 도움이 되면 된다.
- 핵심 업데이트(코어 업데이트)는 사이트 전체 품질을 다시 평가한다. 저품질 글이 쌓이면 좋은 글까지
  같이 떨어질 수 있으니, 검수에서 떨어진 글은 내보내지 않는다.

## 2. 구글이 "신경 쓸 필요 없다"고 한 것 [공식]
아래에 시간을 쓰지 않는다.
- 메타 키워드 태그, 키워드 반복
- 글자 수 최소·최대 목표 (분량 자체는 순위 요소가 아니다. 우리의 1,500자 기준은 검수용 품질 하한일 뿐)
- 도메인·URL에 키워드 넣기 (빵부스러기 표시 외에는 효과 거의 없음)
- 제목 태그 순서(h2 다음 h3 같은 의미 순서)
- 하위 도메인 vs 하위 폴더 선택
- E-E-A-T는 그 자체로 순위 요소가 아니다. 다만 돈·건강 주제는 신뢰 신호와 맞는 글을 더 무겁게 본다고
  구글이 밝혔으니, 출처·정확성·운영자 공개는 그대로 지킨다

## 3. 블로그 전체 구조: 주제 집중과 내부 링크 [공식 + 관행]
- [공식] 비슷한 주제의 글을 묶어 구조를 만들면 구글이 이해하기 쉽다.
- [공식] 중요한 글은 최소 한 곳 이상에서 내부 링크를 받아야 한다.
- 우리 구조:
  - 허브: 월간 정리 글 (그달 모든 단지 글로 링크)
  - 지역 모음 글 (지역 단지 글로 링크)
  - 단지 글 (공고 → 경쟁률 → 당첨 → 무순위를 서로 링크, 월간 허브로 되돌아가는 링크)
  - 기초 가이드 (가점 계산법 등. 단지 글에서 필요한 대목에 링크)
- [관행] 한 주제(청약)만 꾸준히 다루면 그 주제의 '전문 사이트'로 인식되기 쉽다고 보는 시각이 많다.
  구글이 이를 수치로 확인한 적은 없지만, 구글 가이드도 '사이트의 주된 목적'을 점검 질문으로 둔다.
- 라벨(카테고리)은 글당 2~3개, 정해진 목록에서만 고른다: 청약일정, 경쟁률, 당첨가점, 무순위,
  서울, 경기, 인천, 지방, 청약가이드. 라벨을 마구 늘리면 얇은 목록 페이지만 늘어난다.

## 4. 색인(검색에 등록되기) [공식]
- 구글은 주로 다른 페이지의 링크를 따라 새 글을 찾는다. 사이트맵 제출은 필수는 아니지만 돕는다.
- 새 사이트는 반영까지 몇 주~몇 달 걸릴 수 있다. 결과는 최소 몇 주 뒤에 판단한다.
- 같은 내용이 여러 주소로 열리면(모바일 ?m=1 등) 대표 주소(canonical)가 하나여야 한다.
  Blogger 기본 테마는 대표 주소를 넣어 준다(테마 바꿀 때 확인).
- 서치콘솔 '페이지' 보고서에서 '색인 생성되지 않음' 사유를 매주 확인한다.
  '크롤링됨 - 현재 색인이 생성되지 않음'이 많으면 품질 신호가 약하다는 뜻일 수 있으니 글을 보강·통합한다.

## 5. 날짜와 업데이트 [공식]
- 글에 보이는 날짜와 구조화 데이터의 날짜를 일치시킨다.
- 날짜는 글을 쓰거나 고친 날이다. 청약 접수일 같은 사건 날짜를 글 날짜로 쓰지 않는다. 미래 날짜 금지.
- 내용을 실제로 고쳤을 때만 수정일을 바꾼다(정정공고 반영, 경쟁률 추가 등). 날짜만 바꾸는 갱신은 하지 않는다.

## 6. 구글 디스커버(추천 피드) 노출 [공식]
- 가로 1200px 이상, 16:9 큰 이미지 + max-image-preview:large 설정이 권장된다.
- 로고나 글자만 있는 이미지는 피한다. 낚시·과장 제목 금지.
- 우리 블로그는 저작권 문제로 조감도를 쓸 수 없다. 직접 만든 일정·분양가 요약 이미지(표 형태 그래픽)를
  16:9로 만드는 것은 2단계(운영 2개월 뒤) 과제로 둔다.

## 7. 검색 결과 클릭률 높이기 [공식 + 관행]
- [공식] 제목은 글을 정확히 설명하고 짧게. 낚시 제목은 디스커버에서도 불리하다.
- [관행] 제목에 날짜(10월 공고)·숫자(84㎡ 6억대)를 넣으면 최신·구체 정보라는 게 보여 클릭이 늘기 쉽다.
- [공식] 메타 설명에 날짜·가격을 모아 쓰면 스니펫 품질이 좋아질 수 있다.
- 서치콘솔에서 노출은 많은데 클릭률이 낮은 글은 제목과 설명을 고친다(내용이 그대로면 날짜는 바꾸지 않는다).

## 8. 블로그 밖 활동 [공식 + 관행]
- [공식] 잠재 독자가 모이는 커뮤니티에 참여해 사이트를 알리라고 구글도 권한다.
- [관행] 링크를 사고팔거나, 댓글·게시판에 링크를 뿌리는 것은 스팸 정책 위반 위험이 있어 하지 않는다.
- 사용자가 직접 할 수 있다면: 청약 커뮤니티에서 질문에 답하며 관련 글을 공유하는 정도만.

## 9. 사용자 행동 신호에 대해 [사실 확인]
- 체류 시간, 이탈률이 순위에 직접 쓰인다고 구글이 공식 확인한 적은 없다. 이를 노린 꼼수(글 늘이기,
  클릭 유도)는 하지 않는다. 대신 답을 빨리 주고, 관련 글로 자연스럽게 이어지게 한다.

## 10. 운영 루틴과 판단 기준
- 매주: 서치콘솔 노출·클릭·평균 순위·색인 상태 확인. 순위 8~20위 글은 보강.
- 매달: 글 유형별 성과 비교, keyword_rules.md 점수 기준 조정.
- 코어 업데이트 발표 뒤 2주는 큰 변경을 하지 않고 지켜본다. 떨어진 글은 내용을 보강하거나 통합한다.

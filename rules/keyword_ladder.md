# 키워드 사다리: 낮은 검색량에서 높은 검색량으로 (2026-10-14, 4개 블로그 공통)

[사실] 구글은 '블로그 지수'라는 점수를 공개하지 않는다(네이버식 개념). 다만 새 사이트는 신뢰 신호(색인된 글, 다른 사이트의 링크, 검색 노출 기록)가 적어서
검색량이 큰 머리 키워드에서는 뉴스·포털·대형 부동산 사이트를 이기기 어렵다는 것이 업계 공통 경험이다([관행], 구글 공식 수치 없음).
그래서 검색이 적지만 우리만 제대로 답할 수 있는 구체 키워드부터 쓰고, 글과 노출이 쌓이면 더 큰 키워드로 올라간다.

## 1. 단계와 노릴 검색량 구간 (네이버 월간 PC+모바일)
| 단계 | 구간 | 올라가는 조건 [가정] |
| --- | --- | --- |
| 1 | 30~1,500회 | 시작 단계 |
| 2 | 300~5,000회 | 공개 글 30편 이상 + 첫 글 뒤 42일 이상 |
| 3 | 1,000~30,000회 | 공개 글 80편 이상 + 첫 글 뒤 90일 이상 |
- 단계는 data/keyword_stage.json. src/keywords.py가 조건을 넘으면 자동으로 올린다.
- 서치콘솔 데이터를 받게 되면 조건을 '평균 순위 20위 안 키워드 수' 같은 실제 성적으로 바꾼다.

## 2. '낮은 검색량이지만 경쟁력 있는 키워드'의 기준
1. **데이터 우위(가장 중요)**: 키워드의 대상(단지·지역·회사)에 대해 우리 데이터 파일에 계산값이 있다. 남들은 원자료를 옮기지만 우리는 순위·중앙값 대비·비교를 줄 수 있다.
2. **구체성**: 대상 + 주제어. 예) '타워팰리스2차 관리비', '송파구 전세가율', '동원파츠 공모주', '힐스테이트 거제시그니처 분양가'.
3. **구간**: 지금 단계 구간 안. 구간보다 3배 넘게 크면 '머리 키워드'로 보고 제목 키워드로 쓰지 않는다(본문·소제목에 자연스럽게 들어가는 건 괜찮다).
4. **광고 경쟁도**: 네이버 compIdx 낮음 > 중간 > 높음. 순위 난이도가 아니라 상업성 신호라서 약하게만 반영한다.

## 2-1. 성장 적합도: 검색량이 많다고 고르지 않는다 (2026-10-16 추가)
검색량은 '구간 안에 드는가'만 본다. 구간 안에서는 검색이 많은 키워드보다 블로그가 커 가는 데 맞는 키워드를 먼저 쓴다.
src/keywords.py가 아래를 배수로 점수에 곱하고, 이유를 report.md '성장 이유' 칸에 적는다.

| 기준 | 배수 | 이유 |
| --- | --- | --- |
| 같은 대상·같은 의도 글이 이미 있음 | ×0.3 | 우리 글끼리 같은 검색어를 두고 경쟁(키워드 잠식) |
| 이미 쓴 대상의 다른 질문 | ×1.1 | 주제 묶음이 생기고 내부 링크로 서로 힘을 실어 줌 |
| (청약) 지금 쓸 글(jobs)이 답하지 못하는 질문 | ×0.5 | 경쟁률 글로 '분양가' 검색을 잡으려 하면 의도가 어긋남 |
| (청약) 지금 글감 목록에 없는 단지 | ×0.5 | 지금 시점에 쓸 새 정보가 없음 |
| (공모주) 청약일 7일 전~14일 뒤 | ×1.15 | 검색이 몰리는 시기 |
| (공모주) 청약 뒤 한 달 넘음 | ×0.6 | 검색이 줄어듦 |
| (관리비) 주제 글 | ×1.1 | 지역·단지 글을 묶는 허브 글 |

- 쓰는 순서: score 높은 순. 같은 점수면 성장 이유가 있는 것 먼저. volume(검색량)이 크다는 이유만으로 고르지 않는다.
- 매일 09:40 sitecheck 워크플로가 `python src/keywords.py --rescore`로 성장 적합도를 다시 계산한다(검색량은 월·목에만 새로 받음).
- [가정] 배수 값은 처음 정한 값이다. 서치콘솔에서 노출·순위가 쌓이면 실제 성적으로 다시 맞춘다.

## 3. 블로그별 머리 키워드 (제목 키워드로 금지, 검수가 막음)
- 청약노트: 청약, 청약 일정, 아파트 청약, 분양 일정, 무순위 청약, 줍줍, 청약 가점, 청약 경쟁률, 분양가
- 전세 온도계: 전세, 전세가율, 전세 시세, 깡통전세, 아파트 전세, 전세사기, 전세보증보험
- 공모주 뜯어보기: 공모주, 공모주 일정, 공모주 청약, 이번주 공모주, 공모주 수요예측, 공모주 상장 일정
- 관리비 돋보기: 관리비, 아파트 관리비, 관리비 비교, 장기수선충당금, 관리비 평균, 공용관리비
- 키워드는 두 단어 이상(대상 + 주제어). 큰 단지(단지 이름 검색 월 1만 이상)는 세부어를 붙인다: 'OO 84㎡ 분양가', 'OO 당첨 가점 커트라인'.

## 4. 매번 글 쓸 때
1. data/keywords/<블로그>.json의 keywords에서 score 60 이상이고 used가 false인 키워드 가운데, 오늘 글감 대상과 맞는 것을 score 높은 순으로 고른다(검색량 순이 아님, 2-1장).
2. 없으면 '대상 이름 + 주제어'로 직접 만든다(예: '잠실파크리오 관리비'). 머리 키워드는 쓰지 않는다.
3. 같은 키워드로 두 글을 쓰지 않는다.

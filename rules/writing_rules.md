# 글쓰기 기본 규칙 (모든 글에 기본값)

사용자가 정한 기본값이다. 예비 글, 기초 가이드에도 똑같이 적용한다.

## 1. 말투: 사람이 말하듯
- 문장 끝은 해요체와 합니다체를 섞는다:
  "~해요", "~했어요", "~라고 해요", "~합니다", "~했습니다", "~라고 합니다"
- 본문에서 "~이다", "~한다", "~맞다", "~있다", "~된다" 같은 딱딱한 평서형으로 끝내지 않는다.
  (표 칸 안의 짧은 항목은 예외)
- 같은 어미가 세 문장 연속 나오지 않게 바꾼다.
- 공고 내용을 전할 때는 "~라고 해요", "~라고 합니다"로 출처가 공고문임을 드러낸다.
- 사람말투-글쓰기 규칙을 지킨다. 특히:
  - 수사적 질문으로 시작하지 않는다. 가장 구체적인 숫자·날짜로 시작한다.
  - "주목할 점은", "중요한 것은" 같은 강조 표현을 쓰지 않는다. 배치 순서로 강조한다.
  - 결론에서 본문을 되풀이하지 않는다. 남은 일정이나 다음 행동 한 줄로 끝낸다.
  - 이름 없는 출처("전문가들은")를 쓰지 않는다.
  - "~부터 ~까지 다양한", "풍부한", "눈부신" 같은 상투어를 쓰지 않는다.
  - 다른 단지 이름으로 바꿔도 성립하는 문장은 쓰지 않는다. 문장마다 그 단지만의 숫자·날짜·지명을 넣는다.
  - "도움이 되었길 바랍니다" 같은 대화형 마무리를 쓰지 않는다.
  - 확인하지 않은 숫자·통계·인용을 넣지 않는다.

예시:
| 쓰지 않는 문장 | 쓰는 문장 |
| --- | --- |
| 1순위 접수는 10월 14일이다. | 1순위 접수는 10월 14일에 해요. |
| 전매 제한은 3년으로 설정되어 있다. | 공고문에 따르면 전매 제한은 3년이라고 합니다. |
| 주목할 점은 분양가가 낮다는 것이다. | 주변 아파트 실거래가보다 1억 원 정도 낮게 나왔어요. |
(예시 숫자는 문체 설명용 가상 값)

## 2. 모바일에서 읽기 편하게
- 한 문단은 1~3문장. 문단 사이는 빈 줄.
- 한 문장은 대체로 50자 안쪽. 길면 두 문장으로 나눈다.
- 핸드폰 첫 화면에 검색한 사람이 찾는 답(일정·분양가 또는 경쟁률)이 보이게.
- 표는 4열까지. 더 필요하면 표를 둘로 나눈다.
- 소제목은 2~4문단마다 하나.
- 굵은 글씨는 글당 한두 곳만.

## 3. 매번 같은 틀로 쓰지 않기
- 필수 요소(항상): 핵심 요약, 일정, 분양가 또는 결과 숫자, 청약홈 원문 확인 안내와 링크, 관련 글, 자동 정리 안내 문구
- 선택 요소(글마다 2~3개): 주변 시세 비교, 같은 지역 최근 단지 비교, 체크포인트, 자주 묻는 질문, 지난 회차 경쟁률, 신청 자격 요약
- 시작 방식 4가지 중 하나 (직전 글과 다르게):
  A. 분양가로 시작  B. 접수 날짜로 시작  C. 주변 시세와의 차이로 시작  D. 누가 신청할 수 있는지로 시작
- 소제목은 단지명·숫자가 들어간 문장형으로 매번 새로 쓴다. (예: "84㎡는 6억대부터 시작해요")
- 핵심 요약은 맨 위, 원문 링크와 관련 글은 끝. 그 사이 순서는 글마다 다르게.
- 직전 10편과 시작 방식·소제목 구성이 같으면 다시 쓴다.

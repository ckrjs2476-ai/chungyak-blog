# 글별 주제·키워드 규칙

## 1. 오늘 쓸 글 고르기
data/jobs.json에 fetch.py가 점수순으로 후보를 넣어 둔다. 위에서부터 쓴다.
점수 기준(가정, 2개월 뒤 서치콘솔 데이터로 조정):
- 지역: 서울·경기·인천·광역시 가산
- 규모: 공급 세대가 많을수록 가산
- 브랜드: 대형 건설사 단지 가산
- 시점: 공고 직후, 경쟁률 발표 직후, 당첨 발표 당일 가산
- 이미 쓴 단지·유형은 제외 (data/published.json)

후보가 없으면 data/queue/의 예비 글을 쓰거나, 데이터로 만들 수 있는 예비 글을 새로 쓴다
(지역별 모음, 같은 지역 단지 비교, 지난달 결산).

## 2. 글 유형별 키워드
| 유형 | 메인 키워드 | 보조 키워드 | 제목 예시 |
| --- | --- | --- | --- |
| notice (단지 공고) | [단지명] 청약 일정 | 분양가, 모델하우스, 입주자모집공고, 평형, 전매 제한 | OO단지 청약 일정·분양가 총정리 (10월 공고) |
| competition (경쟁률) | [단지명] 경쟁률 | 1순위 마감, 특별공급 경쟁률, 타입별 | OO단지 청약 경쟁률 타입별 정리, 1순위 마감 여부 |
| score (당첨 가점) | [단지명] 당첨 가점 | 커트라인, 최저 가점, 계약 일정 | OO단지 당첨 가점 커트라인, 타입별 최저·최고 |
| remainder (무순위·잔여) | [단지명] 무순위 | 줍줍, 잔여세대, 자격 조건 | OO단지 무순위 청약(줍줍) 일정과 자격 |
| monthly (월간 정리) | [N월] 청약 일정 | 서울·경기 분양, 아파트 분양 일정 | 11월 청약 일정 총정리, 지역별 분양 단지 |
| region (지역 모음) | [지역] 분양 아파트 | [지역] 청약, 미분양 | 경기 남부 분양 아파트 10월 총정리 |

- 메인 키워드는 제목 맨 앞쪽과 첫 문단에 한 번씩. 소제목과 표 제목에 보조 키워드 3~5개.
- 같은 키워드로 두 글을 쓰지 않는다.
- 'OO단지'는 자리 표시. 실제 단지명은 데이터(HOUSE_NM)에서 그대로 가져온다.

## 3. 한 단지를 따라가기
공고 당일 → notice, 1순위 다음 날 → competition, 당첨 발표일 → score, 미달·잔여 발생 → remainder.
각 글은 같은 단지의 앞뒤 글을 서로 링크한다.

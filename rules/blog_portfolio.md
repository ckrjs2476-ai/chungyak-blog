# 블로그 4개 경계 (2026-10-13 확정)

| 블로그 | 다루는 것 | 다루지 않는 것 |
| --- | --- | --- |
| 청약노트 (daily-cheongyak) | 아파트 분양 공고·경쟁률·가점, 분양 단지 vs 주변 매매 시세, 월간 매매 흐름(실거래가 라벨) | 전세, 관리비, 공모주 |
| 전세 블로그 | 전세가율, 전세 거래 흐름, 보증금 위험 신호 (매매가는 전세가율 계산에만) | 매매 시세만 다루는 글, 분양 |
| 관리비 블로그 | 단지별 관리비 비교 (관리비 공공데이터만) | 시세, 전세, 분양 |
| 공모주 블로그 | 공모 일정, 공모 구조(규모·자금 사용처·비슷한 공모 비교) | 아파트 청약. 매수·매도 권유 표현 금지 |

## 겹침 방지 규칙
- 공모주 블로그는 이름과 모든 제목에 '공모주'를 넣는다. '청약노트' 등 청약 블로그와 비슷한 이름을 쓰지 않는다.
- 같은 데이터(매매 실거래가)를 쓰는 청약·전세 블로그는 글 주제로 구분한다: 청약=분양 단지와 주변 시세, 전세=전세가율.
- [사실] 블로그 개수 자체는 대량 생산 정책 대상이 아니다. 정책은 페이지 가치와 순위 조작 목적을 보고, 애드센스 심사도 사이트별이다.
  대량 생산 위험은 각 블로그 안(비슷한 틀의 글 누적)에 있으므로 블로그마다 검수 규칙을 그대로 적용한다.
- [사실] 4개가 같은 애드센스 계정을 쓰므로, 한 블로그의 심각한 정책 위반은 계정 전체에 영향을 줄 수 있다(승인 거절과는 다름).
- [추정, 낮은 우선순위] 출처 문구·카드 색은 블로그 성격에 맞게 다르게 한다.
- 블로그끼리 서로 링크는 최소로 한다.
- 새 블로그는 처음 몇 주 하루 1편(사례 기반 판단, 사용자가 원하면 2편). 애드센스는 블로그마다 src/audit.py 기준을 통과한 뒤 신청한다.

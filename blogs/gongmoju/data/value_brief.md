# 공모주 뜯어보기 오늘 글감 분석 (2026-11-22 15:40 KST)

애드센스 거절 사유 1위 '가치가 별로 없는 콘텐츠'를 피하려고, 글을 쓰기 전에 매번 이 파일을 먼저 본다.
원칙: 이 대상만의 숫자(아래 '두드러진 점')가 2개 이상인 글감만 쓴다. 0~1개면 쓰지 않거나 모음 글로 묶는다.

## 1. 가치가 큰 글감 순서 (아직 안 쓴 것)

- 쓸 후보가 없다. 오늘은 쓰지 않고 이유만 남긴다.

## 2. 오늘 피할 것 (최근 글과 같아 보이면 '틀 반복'으로 읽힌다)

- 최근 글의 시작 방식(opening)·중심(angle): A/공모규모, B/규모, A/수수료, B/일정, C/자금용도, D/주관사
- 최근 3편 소제목(이와 비슷한 소제목·순서 금지): N월 N일부터 N일까지N 청약일과 납입일 순서 / 아델 청약일 N월 N~N일N 마지막 신고서는 N월 N일 / 케이엠에프 공모가 N원N N월 N일 신고서 그대로 / N곳 규모 순위와 수수료율N N곳 안에서 어디쯤인가요? / 시설자금N 운영자금N 채무상환으로 갈린 자금 계획 / 다섯 곳 신고서가 들어온 날짜 순서 / 엠디에스코리아 공모주 자금은 어디에 쓰나요? / 시설자금 N순위 N곳 가운데 세 번째로 쏠린 회사 / N만 주 중 N만 주는 최대주주 쪽이 파는 주식 / 미래에셋증권 단독 인수N 수수료율 N% / 엠디에스코리아 공모가 N원은 확정된 값인가요? / 시설 비중 N%를 읽을 때 갈리는 지점 / 피지티 공모주 수수료율 N%N 같은 값인 네 곳은 어디인가요? / 한국투자증권이 대표 주관인 N곳에서 두 번째로 높은 수수료율 / 한국투자증권 N만 주N 유안타증권 N만 주로 나눈 인수

## 3. 가치를 더하는 방법 (글마다 최소 2개)

- 두드러진 점 하나를 글의 중심으로 삼고, 소제목 1개를 통째로 그 숫자의 의미 해설에 쓴다.
- 비교 대상을 2개 이상 둔다(지역 중앙값 + 같은 규모/같은 방식/같은 시기 등). 비교 없는 숫자 나열 금지.
- 독자 조건별 해설 1문단: '~라면 ~부터 확인' 식으로 상황을 나눈다(권유·판정 없이).
- 원자료 사이트에서 바로 보이는 값(일정, 원래 가격)은 표 1개 안에 몰고, 본문은 계산·비교에 쓴다.
- 다 쓴 뒤 숫자도 이름도 없는 문장을 찾아 지우거나, 이 대상의 숫자를 넣어 고친다.

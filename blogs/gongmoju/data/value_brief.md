# 공모주 뜯어보기 오늘 글감 분석 (2026-11-27 17:48 KST)

애드센스 거절 사유 1위 '가치가 별로 없는 콘텐츠'를 피하려고, 글을 쓰기 전에 매번 이 파일을 먼저 본다.
원칙: 이 대상만의 숫자(아래 '두드러진 점')가 2개 이상인 글감만 쓴다. 0~1개면 쓰지 않거나 모음 글로 묶는다.

## 1. 가치가 큰 글감 순서 (아직 안 쓴 것)

- 쓸 후보가 없다. 오늘은 쓰지 않고 이유만 남긴다.

## 2. 오늘 피할 것 (최근 글과 같아 보이면 '틀 반복'으로 읽힌다)

- 최근 글의 시작 방식(opening)·중심(angle): B/일정, C/자금용도, D/주관사, A/규모비교, B/규모, A/공모규모
- 최근 3편 소제목(이와 비슷한 소제목·순서 금지): N월 N일부터 N월 N일까지N N곳의 청약일과 마지막 신고서 / 아델 공모가 N원N N월 N일 DART에 남은 서류 / 아델 수요예측 결과는 어느 서류에 적히나요? / 총액이 그대로인데 순위가 오른 아델과 케이엠에프 / 중앙값 아래 두 곳N 에이엔에이치스트럭쳐와 엔키화이트햇은 어디서 갈리나요? / 엔키화이트햇 N월 N일 기재정정 신고서 화면 / 스팩 N곳과 DART 자료 기준 / 범한메카텍 공모주 청약 N억 원은 N곳 중 몇 위인가요? / 수수료율 N%N N곳 중 두 번째로 낮은 값 / 범한산업이 내놓는 N만 주N 공모 주식의 N% / 시설자금 N%N N곳 가운데 가장 한쪽으로 몰린 자금 계획 / 범한메카텍 공모가 N원과 수요예측N 바뀔 수 있는 숫자 / 규모 N위 N억 원에 구주 N만 주가 섞였다는 것 / 이노보테라퓨틱스 공모가 N원은 아직 확정 전인가요? / N위에서 N위로N 위에 있던 세 곳이 명단에서 빠졌어요
- 여러 글에 반복되는 표현(쓰지 말 것): 중앙값 N억 원보다 N 커요N / N곳 중앙값 N억 원보다 N / N월 N일 집계 N곳 중 / 총액 N억 원은 N월 N일 / 공모 총액 N억 원은 N월 / N위이고N 중앙값 N억 원보다 N / 계획 N억 원 가운데 N억 / 총액 N억 원은 N곳 중

## 3. 가치를 더하는 방법 (글마다 최소 2개)

- 두드러진 점 하나를 글의 중심으로 삼고, 소제목 1개를 통째로 그 숫자의 의미 해설에 쓴다.
- 비교 대상을 2개 이상 둔다(지역 중앙값 + 같은 규모/같은 방식/같은 시기 등). 비교 없는 숫자 나열 금지.
- 독자 조건별 해설 1문단: '~라면 ~부터 확인' 식으로 상황을 나눈다(권유·판정 없이).
- 원자료 사이트에서 바로 보이는 값(일정, 원래 가격)은 표 1개 안에 몰고, 본문은 계산·비교에 쓴다.
- 다 쓴 뒤 숫자도 이름도 없는 문장을 찾아 지우거나, 이 대상의 숫자를 넣어 고친다.

# 공모주 뜯어보기 오늘 글감 분석 (2026-11-06 11:00 KST)

애드센스 거절 사유 1위 '가치가 별로 없는 콘텐츠'를 피하려고, 글을 쓰기 전에 매번 이 파일을 먼저 본다.
원칙: 이 대상만의 숫자(아래 '두드러진 점')가 2개 이상인 글감만 쓴다. 0~1개면 쓰지 않거나 모음 글로 묶는다.

## 1. 가치가 큰 글감 순서 (아직 안 쓴 것)

- 쓸 후보가 없다. 오늘은 쓰지 않고 이유만 남긴다.

## 2. 오늘 피할 것 (최근 글과 같아 보이면 '틀 반복'으로 읽힌다)

- 최근 글의 시작 방식(opening)·중심(angle): C/수수료, A/자금용도, B/공모규모, A/주관사, B/규모, C/자금용도
- 최근 3편 소제목(이와 비슷한 소제목·순서 금지): KTE 공모주 수수료율 N%는 N곳 중 어디쯤인가요? / 넥스아이 N억 원과 나란히 놓은 수수료 N억 원 / 같은 NH투자증권 단독N 에이엔에이치스트럭쳐는 N% / 발행제비용 N%N 다섯 곳 가운데 가장 얇아요 / KTE 공모가 N원은 아직 신고서 숫자예요 / 시설자금 N억 원N N년에 세운 부산 회사 / 데스틴파워 공모주 N억 원은 N곳 중 몇 번째 크기인가요? / 수수료율 N%를 적은 네 곳N 모두 N억 원 이하 / 한국투자증권 여섯 곳 중 가장 작은 두 공모 / 데스틴파워 공모가 N원N 바뀌면 순위도 움직여요 / 시설 비중 N%N 에스에프씨·하나에어로다이내믹스·씨아이에스케미칼 다음 / 에이엔에이치스트럭쳐 공모주N 빚 갚는 줄 세 곳과 견주면 / N%가 청약하는 사람에게 갖는 뜻 / 규모 N위N 중앙값보다 N% 작아요 / 에이엔에이치스트럭쳐 수요예측 전N 공모가 N원은 확정인가요?

## 3. 가치를 더하는 방법 (글마다 최소 2개)

- 두드러진 점 하나를 글의 중심으로 삼고, 소제목 1개를 통째로 그 숫자의 의미 해설에 쓴다.
- 비교 대상을 2개 이상 둔다(지역 중앙값 + 같은 규모/같은 방식/같은 시기 등). 비교 없는 숫자 나열 금지.
- 독자 조건별 해설 1문단: '~라면 ~부터 확인' 식으로 상황을 나눈다(권유·판정 없이).
- 원자료 사이트에서 바로 보이는 값(일정, 원래 가격)은 표 1개 안에 몰고, 본문은 계산·비교에 쓴다.
- 다 쓴 뒤 숫자도 이름도 없는 문장을 찾아 지우거나, 이 대상의 숫자를 넣어 고친다.

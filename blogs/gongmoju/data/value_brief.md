# 공모주 뜯어보기 오늘 글감 분석 (2026-11-08 17:48 KST)

애드센스 거절 사유 1위 '가치가 별로 없는 콘텐츠'를 피하려고, 글을 쓰기 전에 매번 이 파일을 먼저 본다.
원칙: 이 대상만의 숫자(아래 '두드러진 점')가 2개 이상인 글감만 쓴다. 0~1개면 쓰지 않거나 모음 글로 묶는다.

## 1. 가치가 큰 글감 순서 (아직 안 쓴 것)

- 쓸 후보가 없다. 오늘은 쓰지 않고 이유만 남긴다.

## 2. 오늘 피할 것 (최근 글과 같아 보이면 '틀 반복'으로 읽힌다)

- 최근 글의 시작 방식(opening)·중심(angle): B/공모규모, A/주관사, B/규모, C/자금용도, A/공모규모, D/수수료
- 최근 3편 소제목(이와 비슷한 소제목·순서 금지): 에이엔에이치스트럭쳐 공모주N 빚 갚는 줄 세 곳과 견주면 / N%가 청약하는 사람에게 갖는 뜻 / 규모 N위N 중앙값보다 N% 작아요 / 에이엔에이치스트럭쳐 수요예측 전N 공모가 N원은 확정인가요? / NH투자증권 단독 인수N 수수료율 N% / 신규상장 공모주N 수도권 회사는 N곳 중 몇 곳인가요? / 서울 회사 N곳N 설립 N년 이하가 N곳 / 상장사 수도권 집중과 다른 비수도권 N곳의 자금 표 / 대표 주관사는 지역과 겹치지 않아요 / 본점 지역을 신고서와 함께 읽을 때 나눠 볼 경우 / 본점 주소와 공모 숫자를 가져온 서류 / N주당 공모가 N원부터 N원까지N N곳은 이렇게 나뉘어요 / 공모주 청약 증거금N 같은 N주인데 금액이 왜 다른가요? / 공모주 청약 계산기에 유캐스트와 넥스아이를 넣어 보니 / 공모가 N원 KTE와 유캐스트의 수수료율 차이

## 3. 가치를 더하는 방법 (글마다 최소 2개)

- 두드러진 점 하나를 글의 중심으로 삼고, 소제목 1개를 통째로 그 숫자의 의미 해설에 쓴다.
- 비교 대상을 2개 이상 둔다(지역 중앙값 + 같은 규모/같은 방식/같은 시기 등). 비교 없는 숫자 나열 금지.
- 독자 조건별 해설 1문단: '~라면 ~부터 확인' 식으로 상황을 나눈다(권유·판정 없이).
- 원자료 사이트에서 바로 보이는 값(일정, 원래 가격)은 표 1개 안에 몰고, 본문은 계산·비교에 쓴다.
- 다 쓴 뒤 숫자도 이름도 없는 문장을 찾아 지우거나, 이 대상의 숫자를 넣어 고친다.

## 1. 글감 고르기
- plan.md 후보 중 아직 안 쓴 것(published.json의 keyword와 비교) 위에서부터. 직전 글과 같은 type이면 다음 후보로.
- 후보를 다 썼으면 keywords.md에서 '제외'가 아니고 네이버 월 20~400, 아직 안 쓴 키워드를 고른다. 이미 쓴 글과 같은 질문이면 안 된다(겹침 금지).
- 쓰지 않는 것(2026-12-31까지): 자격증 필기·실기·종류별 취득·비용·국비/국가 지원·학원 비교. 검수가 막는다.
- 사용자의 다른 드론 블로그(다른 프로젝트)와 같은 키워드를 쓰더라도 내용·구성·표는 완전히 다르게 쓴다. 다른 사이트 글을 보고 쓰지 않는다.

## 3. 머리말
```
---
type: rule            # basic | rule | job | news
title: "드론 기체신고 대상, 250g 넘으면 …"   # 키워드 첫 단어를 앞 25자 안에, 60자 이하
slug: "drone-registration-weight-2026"
description: "50~160자, 검색 결과에 나올 요약"
labels: [드론 규정]   # type에 맞는 라벨 1개(+필요하면 1개 더): 드론 기초·드론 규정·드론 직업·드론 소식
keyword: "드론 기체신고 대상"
answer: "이 글의 한 줄 답(20~120자). 글 맨 위 상자로 나간다"
opening: A            # A~D, 직전 글과 다르게
angle: 기준           # 방법|비교|기준|변화|현장|오해, 같은 type 직전 2편과 같게 연속 금지
topic_id: "registration"
questions: ["드론 기체신고 대상", "드론 기체신고 기준"]  # 실제 검색 질문 2개 이상(keywords.json google_suggest 등에서 본 말)
---
```

## 4. 본문 구조 (SEO·AEO·GEO)
- 첫 문단 2~3문장에 질문의 답을 바로. 그다음 이 글이 더하는 것(비교표, 원문 확인, 절차).
- 소제목(##) 4~6개, 일부는 실제 검색 질문 형태. 소제목 아래 첫 문장은 답부터.
- 표 1개 이상(기준 비교, 절차, 직업별 하는 일 등). 용어는 처음 나올 때 한 줄로 풀이.
- 공식 출처 링크를 본문 문장 안에 1개 이상, 확인일을 "2026년 10월 30일 기준"처럼 적는다(검수가 확인).
- 1,600자 이상. 같은 블로그 다른 글로 문맥 링크 1~2개(있을 때).
- 마무리는 결론 되풀이 대신 "실제로 날리기 전 확인할 곳" 같은 다음 행동 하나.

## 4-1. 새 글 8가지 기준 (2026-10-30 원고부터 검수가 막음, 근거 rules/seo_guide.md 13장)
- 머리말에 `questions: ["실제 검색 질문1", "질문2"]`(2개 이상, keywords 목록·검색 화면 자동완성·연관검색어에서 실제로 본 말 그대로, 지어내지 않음) → 그 말이 소제목 2개 이상에.
- 질문형 소제목 1개 이상(드론 2개), 바로 아래 첫 문장은 답. 빈 소제목(정리·마무리·결론) 금지.
- 핵심 용어 하나를 한 문장으로 정의("OO는 ~을 말해요", "OO는 ~로 계산한 값이에요", "OO는 ~하는 제도예요" 등, 글마다 다른 용어·표현).
- 문단은 떼어 읽어도 통하게: '이는·그래서·하지만'으로 시작하는 문단 2개까지.
- 공식 자료 링크 1개 이상, 같은 블로그 LIVE 글 문맥 링크 1~2개(published.json url만).
- 블로그 전체 겹침 금지(seo_guide 13장 7번): 대표 키워드가 같은 글, 같은 대상·같은 종류 글이 이미 있으면 쓰지 않는다. 대표 키워드가 달라도 소제목·구성·문장·마무리가 기존 글과 겹치면 검수가 막는다. 쓰기 전에 published.json에서 비슷한 글 제목·소제목(headings_pattern)을 먼저 본다.

## 5. 경험·캡처 (rules/capture_guide.md 6장)
- 실제로 연 화면만 1인칭으로: "드론원스톱에서 비행승인 메뉴를 열어 보니 …"(캡처 첨부), "법령 원문에서 이 조항을 찾아보니 …", "국토부 보도자료를 '드론'으로 검색해 보니 …".
- 캡처 레시피(capture_guide 3장 드론 줄): 드론원스톱 첫 화면, 국토부 보도자료 '드론' 검색 결과, 법령 원문, 고용24 '드론' 채용 검색. 글 하나에 1장 정도.
- 쓰지 않는 경험: 직접 비행, 교육원 방문·수강, 시험 응시, 장비 구매·사용 후기, 지인 사례.
